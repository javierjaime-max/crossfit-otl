# CrossFit OTL — Facility

## Identity

- **DBA:** CrossFit OTL (a DBA of Fit4 Associates Inc., S Corp)
- **Location:** North Richland Hills, TX (DFW Mid-Cities area)
- **Opened:** February 2022

## Space Layout

The gym is a single large floor divided into functional zones:

- **Front zone:** Rig, pull-up bars. Primary zone for movements requiring the rig or the front of the floor.
- **Back zone:** Accessible via back door. Used for overflow, running-heavy workouts, or classes with small footprint (dumbbells, no rig). Back door = access to outdoor running area.
- **Whiteboard:** Location varies by class setup — see `class-management.md` for positioning logic.
- **Coach's table:** Positioned based on class setup — see coaching notes.

**Zones are assigned per class each day based on space allocation logic in `class-management.md`.**
