# CrossFit OTL — Door Protocols and Access

> This atom is a skeleton. All fields marked NEEDS_JAVIER must be filled in via voice capture or direct input before role SOPs can be generated from this.

## Doors

| Door | Location | Used For |
|---|---|---|
| Front door | Main entrance | Member entry/exit, standard traffic |
| Back door | Rear of facility | Outdoor running access, back-zone class traffic |

## Opening Sequence

**NEEDS_JAVIER — capture the full open sequence:**

1. Arrival time before first class (5AM class → coach arrives at?)
2. Entry method: key? keypad code? fob?
3. Alarm disarm: code, location of panel, time window before it triggers
4. Back door: separate key/code, or same?
5. Any lights/HVAC to activate on arrival
6. Any equipment to pull out or arrange before members arrive
7. Whiteboard setup — what goes on it, who writes it

## Closing Sequence

**NEEDS_JAVIER — capture the full close sequence:**

1. Who is responsible for closing each day (last class coach, or designated closer?)
2. Equipment put-away standard — what goes where
3. Lights, fans, HVAC off
4. Back door check before exit
5. Alarm set: code, exit window
6. Front door lock: key? keypad? auto-lock?
7. Any end-of-day cleaning standard

## Access Authorization

**NEEDS_JAVIER:**

- Who has a key / fob / code: names and roles
- Process for granting access to a new coach
- Process for revoking access when a coach leaves
- Member early-morning access (if any — some affiliates use app-based entry for 5am self-coached members)

## Emergency Access

**NEEDS_JAVIER:**

- After-hours contact if a coach is locked out
- Locksmith or building management contact
- What to do if the alarm is triggered accidentally

## Alarm System

**NEEDS_JAVIER:**

- Alarm company name and contact
- Account number (store securely — do not include raw codes here)
- Who to call if a false alarm needs to be cleared with the monitoring company
